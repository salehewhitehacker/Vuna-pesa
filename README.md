# Vuna Pesa Tanzania

Vuna Pesa ni app ya kisasa kwa ajili ya survey, uwekezaji wa mazao, vocha, kikoba, na michezo.
Ina sehemu za kujisajili, login, dashboard, investment, offers, brokers, game, chat, survey sector 15, menu modern, na settings.

## Features
- Jisajili na login (namba ya simu, NIDA, nchi, mtandao wa simu, bank 30, kazi 30, email, password)
- Uwekezaji wa mazao (50+ types), market chat live, vocha mitandao (Halotel, Vodacom, Airtel, TCCL, Mixx by Yas)
- Kikoba - group, invite link, activities
- Brokers 5 (majina, namba)
- Survey sekta 15, teknolojia, afya, kilimo, science, nk.
- Bootstrap modern, responsive (mobile/tablet/desktop)

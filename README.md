## Vuna Pesa - Features

- Modern signup/login
- Investment in crops (mahindi, maharage, alizeti, 50 types)
- Vocha network management (Halotel, Airtel, Vodacom, TCCL, Mixx)
- Kikoba - create savings group
- Survey sectors (Afya, Kilimo, Science, Teknolojia, History, n.k. 15+)
- Admin panel (block users, activate orders, edit voucher, message users)
- Withdrawals / Orders (approve/cancel)
- Payment integration (API, consumer/secret key, domain, callback)
- Chat/Broker management
- Team & Support section
- Notifications, settings
- About, FAQ, Privacy, Terms

## Command Za Kuendesha Website/Server (Termux/KaliLinux/CLI)
**Below are the 50+ commands you can use for server setup, development, deployment, and management:**

### 1. GitHub Clone
```
git clone https://github.com/johntemu1986-cmd/Vuna-pesa.git
```

### 2. Change Directory
```
cd Vuna-pesa
```

### 3. Open in VSCode
```
code .
```

### 4. Start Simple HTTP Server (Python)
```
python3 -m http.server 8080
```

### 5. Start Live Server (Nodejs)
```
npx http-server . -p 8080
```

### 6. Install npm dependencies
```
npm install
```

### 7. Run Project (if using Node project)
```
npm start
```

### 8. Setup on Termux (Android)
```
pkg install git
pkg install python
git clone https://github.com/johntemu1986-cmd/Vuna-pesa.git
cd Vuna-pesa
python3 -m http.server 5000
```

### 9. Setup on Kali Linux
```
sudo apt update
sudo apt install git python3
git clone https://github.com/johntemu1986-cmd/Vuna-pesa.git
cd Vuna-pesa
python3 -m http.server 4000
```

### 10. Deploy GitHub Pages
```
git add .
git commit -m "Update website"
git push
```

### 11. Dockerize Project (Optional)
```
docker build -t vunapesa-image .
docker run -p 8080:80 vunapesa-image
```

### 12. Remove unused files

rm -rf oldfiles/

ls -l
